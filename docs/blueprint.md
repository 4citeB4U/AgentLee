# **App Name**: Agent Lee Assistant

## Core Features:

- Voice Command Interpretation: Voice command recognition and natural language understanding powered by Google Gemini. Converts user speech into text and interprets intent.
- Email Composition Tool: Uses Gemini LLM with access to a tool for composing email.
- Weather Information Tool: Uses Gemini LLM with access to a tool for accessing weather information.
- Voice Feedback: Text-to-speech (TTS) functionality for voice feedback and responses, selectable voice (Sharon or Carl).
- LiveKit Integration: Integrates with LiveKit for real-time audio streaming and communication.
- UI/UX Design: Streamlined UI for displaying transcriptions and agent responses, with real-time updates.
- Secure API Key Management: Secure handling of API keys (LiveKit, Gemini, etc.) using .env files.

## Style Guidelines:

- Primary color: A deep, calm blue (#4682B4) reminiscent of reliable digital assistants. This hue evokes trust and sophistication, aligning with the agent's helpful role.
- Background color: A very light desaturated blue (#E6EBF0), almost grey. Provides a neutral, calming backdrop that reduces eye strain and enhances focus on content.
- Accent color: A muted purple (#8072A3), used sparingly for interactive elements and highlights, conveying intelligence and creativity without being distracting.
- Font pairing: 'Space Grotesk' (sans-serif) for headlines, providing a modern, tech-focused aesthetic, combined with 'Inter' (sans-serif) for body text to ensure readability.
- Simple, clear icons for tools and status indicators; aim for consistency with Android's Material Design principles.
- Clean, card-based layout for information display, ensuring a logical content flow and ease of use on mobile devices.
- Subtle animations for loading states and transitions, providing visual feedback without disrupting the user experience.
